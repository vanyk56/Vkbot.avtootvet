# 🤖 VK Селф-бот (Userbot) — Полное руководство

Мощный, быстрый и полностью асинхронный селф-бот (юзербот) для ВКонтакте на базе **Python 3 (asyncio, aiohttp, aiosqlite)**.
Бот управляется командами прямо из сообщений ВКонтакте, автоматически редактирует сообщения на красивые отчёты и выполняет фоновые задачи (ферма Ириса, автоответчик, циклические таймеры, чистка собачек и др.).

## 💡 Как устроен и работает селф-бот

* **В отличие от бота группы**, селф-бот работает от имени **вашего личного профиля ВКонтакте**.
* **User LongPoll**: бот в реальном времени слушает поток входящих и исходящих событий с задержкой всего 15–40 миллисекунд.
* **Редактирование команд**: когда вы пишете команду (например, `нб +ферма`), бот перехватывает ваше сообщение и **редактирует его на отчёт**, не создавая спама и мусора в чате.
* **Параллельная асинхронность**: таймеры, сбор бонусов в Ирисе, автоответчик и проверка заявок крутятся в фоне независимо и не тормозят переписку.
* **База данных SQLite**: настройки тумблеров, шаблоны, циклические таймеры, баланс и списки сохраняются в локальный файл `bot.db`.

## 🔑 Где и как получить токен ВКонтакте

Для работы селф-бота необходим **User Access Token** (токен пользователя) с разрешениями:
`messages, friends, photos, status, wall, offline, docs, groups, audio`.

> **Важно**: Токен сообщества/группы **не подойдёт**, так как он не умеет редактировать личные сообщения пользователя или выходить из бесед от его лица.

### Как получить токен безопасно:
1. **Через Kate Mobile OAuth / Сервис VKHost**:
   - Откройте проверенный генератор токенов (например, [vkhost.github.io](https://vkhost.github.io/)).
   - Выберите приложение **Kate Mobile** или **VK Admin**.
   - Нажмите «Разрешить доступ».
   - Из адресной строки браузера скопируйте параметр `access_token=vk1.a.xxxx...` (от знака `=` до знака `&`).
2. Вставьте скопированный токен в файл `.env`:
   ```env
   VK_TOKEN=vk1.a.ваш_токен_здесь
   ```

## 📋 Полный список команд и модулей

Везде, где указано `преф`, подразумевается текущий префикс (по умолчанию: **`нб`**).

### 1. Переключатели (On/Off)
* `преф префикс [буква/слово]` — смена префикса команд (например: `нб префикс б` -> теперь команды вызываются через `б инфо`).
* `преф +ферма` / `преф -ферма` — включить/выключить автоматический сбор бонусов и работы в боте Ириса.
* `преф +автовыход` / `преф -автовыход` — бот автоматически выходит из любых новых бесед, куда вас добавляют.
* `преф +автопуши` / `преф -автопуши` — автоматическое прочтение упоминаний (@all, @online и тегов).
* `преф +автоотписка` / `преф -автоотписка` — автоматическая отписка от неактивных друзей (>90 дней офлайн) и удаленных страниц.
* `преф +оффлайн` / `преф -оффлайн` — скрытие сетевого статуса (режим «вечный оффлайн»).
* `преф +адвд` / `преф -адвд` — автоматическое принятие всех входящих заявок в друзья.
* `преф +собачки` / `преф -собачки` — авто-очистка списка друзей от заблокированных аккаунтов («собачек»).
* `преф +автоответчик` / `преф -автоответчик` — включить/выключить автоответчик в ЛС.
* `преф автоответчик [текст]` — задать текст автоответчика.
* `преф +уведы` / `преф -уведы` — переключение системных уведомлений.
* `преф +деж` / `преф -деж` — включение режима «Дежурный» (разрешает доверенным лицам использовать команды).

---

### 2. Ферма в боте Ириса
* `преф +ферма` — активирует сбор в текущей беседе (где написана команда) или диалоге с Ирисом.
* Бот автоматически отправляет команды:
  - «Ферма» (раз в 4 часа)
  - «Работа» (раз в 4 часа)
  - «Шахта» (раз в 4 часа)
  - «Копать» (раз в 2 часа)
  - «Бонус» (раз в 24 часа)
* `преф ферма инфо` — красивый экран с точным таймером обратного отсчета до каждой команды (часы, минуты, секунды).

---

### 3. Циклический таймер (цтаймер)
Позволяет настроить периодическую отправку любого сообщения в текущий чат по заданному времени!
* `преф +цтаймер 1ч 30с Привет чат!` — запускает отправку текста «Привет чат!» каждые 1 час и 30 секунд.
* `преф +цтаймер 15м копать` — отправка текста «копать» каждые 15 минут.
* `преф +цтаймер 45с Спамим` — отправка текста каждые 45 секунд.
* `преф цтаймеры` — выводит список всех активных циклических таймеров с их ID.
* `преф -цтаймер [ID]` — останавливает и удаляет таймер с указанным ID.

---

### 4. Утилиты владельца
* `преф повторялка [символ/текст]` — дублирует указанный текст заданное количество раз (например `нб повторялка 🔥`).
* `преф удалялка` — просмотр текущих стоп-слов (по умолчанию `дд`).
* `преф удалялка +[слово]` / `преф удалялка -[слово]` — добавить/удалить стоп-слово.
  - *Как работает*: если вы напишете `дд` в любой чат, бот мгновенно сотрет само это сообщение и ваши предыдущие сообщения в чате.
* `преф редач [текст]` — эффектное редактирование сообщения на новый текст с эффектом печатной машинки.

---

### 5. Модерация и управление пользователями
Любая команда принимает цель как **ответом на сообщение (реплай)**, так и **прямой ссылкой / упоминанием / ID**:
* `преф вернуть [ссылка / ответ]` — возвращает пользователя обратно в беседу.
* `преф кик [ссылка / ответ]` — исключает пользователя из текущей беседы.
* `преф +админ [ссылка / ответ]` — назначить администратором беседы.
* `преф -админ [ссылка / ответ]` — разжаловать до обычного участника.
* `преф +игн [ссылка / ответ]` / `преф -игн` — добавить/убрать из локального игнор-листа (сообщения игнорируемых мгновенно стираются).
* `преф игнлист` — список всех людей в игноре.
* `преф +чс [ссылка / ответ]` / `преф -чс` — заблокировать/разблокировать человека в ЧС ВКонтакте.
* `преф чсы` — список заблокированных пользователей.
* `преф +дов [ссылка / ответ]` / `преф -дов` — добавить/убрать из списка доверенных лиц («довы»).
* `преф довы` — список доверенных пользователей.
* `преф +др [ссылка / ответ]` / `преф -др` — добавить в друзья / удалить из друзей.

---

### 6. Шаблоны (Текст и Голосовые сообщения)
#### Текстовые шаблоны:
* `преф +шаб [имя]` (в ответ на сообщение) — сохранить текст в шаблон.
* `преф -шаб [имя]` — удалить текстовый шаблон.
* `преф шабы` — список всех текстовых шаблонов.
* `преф шаб [имя]` — моментально отправить сохраненный шаблон в чат.

#### Голосовые шаблоны (ГС):
* `преф +гс [имя]` (в ответ на голосовое сообщение) — перехватывает аудиосообщение и сохраняет его в базу.
* `преф -гс [имя]` — удалить голосовой шаблон.
* `преф гсы` — список всех голосовых шаблонов.
* `преф гс [имя]` — отправляет сохранённую запись **именно как нативное голосовое сообщение**, а не как аудиофайл/документ!

---

### 7. Информационные команды и Инструменты
* `преф инфо` / `преф профиль` / `преф я` — полная карточка статуса бота: тумблеры (✅/❌), таймер фермы, баланс фортантов, премиум и настройки.
* `преф помощь` / `преф кмд` — подробная справка по всем командам.
* `преф пинг` / `преф форматтер пинг` — измерение пинга и задержки LongPoll сервера.
* `преф беседа` — информация о беседе (ID чата, создатель, число участников, число «собачек», статус админки).
* `преф онлайн` — список всех участников текущей беседы, находящихся прямо сейчас в сети.
* `преф ава [ссылка / ответ]` — присылает аватарку пользователя в максимальном разрешении.
* `преф гороскоп` — астрологический прогноз на текущий день.
* `преф вк ми` — генерация короткой ссылки типа `vk.me/` на профиль или беседу.
* `преф брак помощь` — правила виртуальных браков.

---

### 8. Массовые действия и пуши
* `преф прочитать [все / чаты / группы / беседы]` — помечает все непрочитанные диалоги выбранной категории как прочитанные.
* `преф очистить [все / чаты / группы / беседы]` — выходит из бесед или удаляет диалоги.
* `преф влс [текст]` — массовая рассылка указанного сообщения по всем открытым личным диалогам.
* `преф мегапуш` — тегает абсолютно всех участников беседы пачками до 25 человек (доступно с Премиумом).
* `преф пуши [боты / алл / все]` — настройка фильтрации упоминаний (`боты` — игнор ботов, `алл` — игнор @all/@online, `все` — все пуши).

---

### 9. Лайки и Интерактив
* `преф +лайк [ссылка / ответ]` — поставить лайк на аватарку или первый пост со стены.
* `преф -лайк [ссылка / ответ]` — снять лайк.
* `преф лайки [ссылка / ответ]` — показывает количество лайков и статус вашего лайка.
* `преф брак [ссылка / ответ]` — сделать предложение руки и сердца / принять предложение.
* `преф развод` — расторгнуть брак.
* `преф стикеры` — выводит список всех купленных и доступных стикерпаков аккаунта.

---

### 10. Локальная Экономика и Премиум
* `преф баланс` — показывает ваш баланс в валюте бота («фортанты»).
* `преф передать [ссылка / ответ] [кол-во]` — перевести фортанты другому пользователю.
* `преф +премиум [кол-во месяцев]` — покупка премиум-статуса (из расчета **50 фортантов за 1 месяц**).
  - *Преимущества Премиума*: доступ к команде `мегапуш`, увеличение лимита команды `авкол` до 100 повторений, статус ⭐ в профиле.

---

### 11. Режим «Дежурный»
* `преф +деж` / `преф -деж` — переключатель режима «Дежурный».
* При включенном дежурном пользователи, добавленные в список «Доверенные» (`преф +дов`), могут выполнять команды бота на вашем аккаунте (например, для координации и модерирования сетки бесед).

## ☁️ Развертывание 24/7 на Railway

Бот полностью подготовлен для работы на облачной платформе [Railway.app](https://railway.app/).

### Пошаговое развертывание:
1. **Загрузите репозиторий на GitHub**:
   - Создайте репозиторий (рекомендуется **Private**, чтобы скрыть ваш код).
   - Запушьте проект (файл `.env` автоматически игнорируется `.gitignore` и не попадет в открытый доступ).
2. **Создайте проект на Railway**:
   - Перейдите на [Railway Dashboard](https://railway.app/dashboard).
   - Нажмите **New Project** -> **Deploy from GitHub repo** -> выберите ваш репозиторий.
3. **Настройте переменные окружения (Variables)**:
   - В панели проекта перейдите во вкладку **Variables**.
   - Добавьте переменную:
     - `VK_TOKEN` = `vk1.a.ваш_токен_пользователя`
     - *(Опционально)* `DEFAULT_PREFIX` = `нб`
4. **(Рекомендуется) Подключите Volume для базы данных**:
   - Нажмите правой кнопкой на сервис бота в Canvas -> **Add Volume**.
   - Укажите путь монтирования (Mount Path): `/data`.
   - Добавьте в **Variables** переменную: `DATA_DIR` = `/data`.
   - Теперь файл базы данных `bot.db` будет сохраняться даже при перезапусках контейнера!
5. **Запуск**:
   - Railway автоматически соберет Docker-образ по [`Dockerfile`](file:///C:/Users/vanap/.gemini/antigravity/scratch/vk_selfbot/Dockerfile) и запустит селф-бота.
   - В логах (Deploy Logs) появится надпись: `👂 Подключение к User LongPoll... Бот готов к работе!`.
